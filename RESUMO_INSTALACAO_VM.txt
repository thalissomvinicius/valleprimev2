================================================================================
  VALLEPRIME API - INSTALAÇÃO NA VM HORIZON (RESUMO RÁPIDO)
================================================================================

📋 SITUAÇÃO:
Você tem acesso apenas às pastas compartilhadas da VM (como pasta de rede).
Não tem acesso a terminal, PowerShell ou instalação de serviços.

================================================================================
  PASSO A PASSO (10 MINUTOS)
================================================================================

1️⃣ NA SUA MÁQUINA LOCAL:
   
   a) Abra PowerShell na pasta: modulo_api_corretores
   b) Execute: powershell -ExecutionPolicy Bypass -File deploy_vm_automatico.ps1
   c) Uma pasta será aberta com os arquivos prontos

--------------------------------------------------------------------------------

2️⃣ ACESSAR PASTA DA VM:

   a) Abra o Explorer
   b) Navegue até a pasta compartilhada da VM, exemplo:
      \\VMHORIZON\C$\Users\TCRUZ\Desktop
      ou
      \\tsclient\C\Users\TCRUZ\Desktop
   
   c) Crie uma nova pasta chamada: VallePrimeAPI

--------------------------------------------------------------------------------

3️⃣ COPIAR ARQUIVOS:

   a) Selecione TODOS os arquivos da pasta preparada (Ctrl+A)
   b) Copie (Ctrl+C)
   c) Cole na pasta VallePrimeAPI da VM (Ctrl+V)
   d) Aguarde a cópia terminar

--------------------------------------------------------------------------------

4️⃣ CONFIGURAR CREDENCIAIS:

   a) Na pasta da VM, renomeie: .env.template → .env
   b) Abra o .env com Bloco de Notas
   c) Preencha suas credenciais:
      - UAU_USER=seu_usuario
      - UAU_PASSWORD=sua_senha
      - SUPABASE_URL=sua_url
      - SUPABASE_SERVICE_ROLE_KEY=sua_chave
   d) Salve (Ctrl+S) e feche

--------------------------------------------------------------------------------

5️⃣ INICIAR A API:

   a) Dê duplo clique em: INSTALAR.bat
   b) Uma janela preta vai abrir
   c) Aguarde aparecer: "API INICIADA COM SUCESSO!"
   d) NÃO FECHE ESTA JANELA! (minimize ela)

--------------------------------------------------------------------------------

6️⃣ TESTAR:

   a) Abra o navegador na VM
   b) Acesse: http://localhost:8001/health
   c) Deve aparecer: {"status": "healthy", ...}
   d) Funcionou! ✅

================================================================================
  MANTER RODANDO 24/7
================================================================================

OPÇÃO A: Deixar a janela aberta
   - Minimize a janela preta
   - Não feche ela
   - A API roda enquanto ela estiver aberta

OPÇÃO B: Inicialização automática
   - Copie o INSTALAR.bat
   - Cole em: \\VMHORIZON\C$\Users\TCRUZ\AppData\Roaming\Microsoft\Windows\Start Menu\Programs\Startup
   - Agora inicia automaticamente quando a VM ligar!

================================================================================
  PROBLEMAS COMUNS
================================================================================

❌ "Python não encontrado"
   → Python precisa estar instalado na VM
   → Peça ao TI para instalar Python 3.8+

❌ "Erro ao conectar no UAU"
   → Verifique credenciais no arquivo .env
   → Confirme usuário e senha do banco

❌ "Arquivo .env não encontrado"
   → Certifique-se de renomear .env.template para .env
   → O nome deve ser exatamente .env (com ponto)

❌ "Janela fecha sozinha"
   → Houve um erro
   → Abra: logs\service_stderr.log
   → Veja qual foi o erro
